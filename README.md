# A.C. Projects — сайт кровельной фирмы

Статический одностраничный сайт: без сборки, без сервера, без npm.
Языки: нидерландский (по умолчанию), французский, английский.

**Как опубликовать (GitHub + Netlify), пошагово:** [DEPLOY.md](DEPLOY.md), инструкция на английском.

## Структура

```
A.C.Project/
├── public/               САЙТ: всё, что видят посетители
│   ├── index.html        главная страница (разметка + скрытая форма для Netlify Forms)
│   ├── 404.html          страница «не найдено»
│   ├── assets/
│   │   ├── css/style.css     все стили
│   │   ├── js/main.js        3D-ратуша, анимации, тексты на 3 языках, форма заявки
│   │   └── img/favicon.svg   иконка сайта
│   ├── robots.txt        правила для поисковиков
│   ├── sitemap.xml       карта сайта для Google
│   └── site.webmanifest  название и иконка для телефонов
├── netlify.toml          Netlify публикует папку public, сборки нет
├── .gitignore            что не загружать на GitHub (.claude)
├── README.md             эта заметка
└── DEPLOY.md             инструкция по публикации
```

Локально сайт открывается двойным кликом по `public/index.html`.
Скрытая папка `.claude` нужна только для проверки на компьютере, на GitHub её не загружать.

## Заявки

- В начале `public/assets/js/main.js` есть блок `SITE_CONFIG`. Сейчас там `formEndpoint: 'netlify'`, то есть заявки идут в Netlify Forms (форма `offerte`).
- При открытии с диска заявка не отправляется, посетитель видит только сводку.
- Для другого хостинга вместо `'netlify'` можно указать адрес Formspree или Web3Forms (подсказка в комментарии в том же файле).
- Фото в заявку не прикладываются, передаются только имена файлов.

## Перед запуском

1. Домен: в `public/robots.txt` и `public/sitemap.xml` заменить `https://www.example.be`.
2. Политика конфиденциальности (privacybeleid). В Бельгии обязательна, текст нужен от фирмы.
3. Проверить переводы и обещания «Gratis en vrijblijvend» и «zo snel mogelijk contact».

## Что ещё можно улучшить

- Шрифты подключить локально, а не через Google Fonts: лучше для GDPR и скорости.
- Картинка превью для соцсетей (`og:image`, 1200×630), `og:url` и `canonical` в `index.html`.
- Блоки 2–5: «Wat zit erin», преимущества, кнопка заказа, подвал с контактами и реквизитами (KBO / BTW).
